# ShetabPy
**ShetabPy** is an AOT-oriented, full-stack Python framework by Desi Script, designed to bring compile-time application processing, optimized runtime execution, and a modern React development experience to Python.

Inspired by the developer experience of Shetab and the build-time augmentation philosophy of frameworks like Quarkus, ShetabPy aims to simplify application development while minimizing runtime overhead.

**Key goals:**
- Ahead-of-Time (AOT) application compilation and optimization
- Decorator-driven routing and application configuration
- Compile-time dependency injection and resolution
- Full-stack React and TypeScript integration
- Server-Side Rendering (SSR), Static Site Generation (SSG), and Incremental Static Regeneration (ISR)
- Automatic TypeScript type generation
- Optimized request handling and serialization
- Modern development and production tooling

**ShetabPy — Python development, reimagined around AOT.**
